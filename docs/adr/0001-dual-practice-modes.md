# 练习与模拟测试双模式

原 MVP 只有一条线性刷题流程（随机 10/20 题 → 逐题提交 → 跳解析页 → 返回），首页交互无法满足产品定位。经 grill-with-docs 讨论，将刷题拆为两种并列模式：**练习**（教练角色，单科聚焦，答一题判一题原地反馈，轻量小结）与**模拟测试**（考官角色，组卷范围可配，限时遵循真实考试节奏，过程不判分不给答案，交卷出具报告）。两条流程页面独立、不共用。

Status: accepted

**考虑过的方案**:单一统一刷题流程（原 MVP 形态）。否决——教练与考官两种交互在反馈时机、限时、成绩呈现上需求相反，揉在一条流程里会同时损失练习的专注与模拟的真实性。

**连带结果**:
- 原「解析页」降级为「记录详情页」，承担错题回顾与记录回看，不再参与练习主流程
- 模拟测试需要引入「会话」概念落库，记录答题进度与剩余时间以支撑中断续考
- 薄弱点从展示列表变为可点击的考点练习入口，与练习单科聚焦打通

**交互细节**:见 `CONTEXT.md` 术语表（练习 / 模拟测试 / 报告 / 小结 / 中断续考 / 薄弱点 / 范围 / 连续打卡）。
