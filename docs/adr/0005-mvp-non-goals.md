# MVP 范围与非目标：明确不做清单（范围护栏）

竞品（医考帮 / 蓝基因 / 昭昭）普遍提供每日一练、打卡、社区等"标配功能"，外部参考文档也把每日一练 / 热门考点 / 备考视频列为"核心模块"。而本项目硬约束是 2026-12 初试、MVP 需 2026-11 前内测可用、单人开发——**窗口期内每一周都是不可逆的时间支出**。Q11（2026-08-01）决定 MVP 只做核心闭环：刷题 → 解析 → AI 追问 → 薄弱点 → 考点标签 + 配额计数。

本 ADR 把「明确不做」固化为清单，防止开发途中被"竞品都有"诱惑而范围蔓延。非目标 ≠ 永不：每项带重估条件。

Status: accepted（2026-08-06）

**决策核心（MVP 明确不做）**:

| 非目标 | 含义 | 何时重估 |
|---|---|---|
| 每日推荐 / 每日一练 | 系统每天自动推题 | **已进入重估**（2026-08-06）：首页第四入口候选、按刷题表现算法推荐，机制合并进 P2「每日推荐重估」；MVP 仍不做 |
| 自动出小测 | 按薄弱点自动生成测试 | 薄弱点三态诊断积累足够数据后（当前"自适应抽题"已在 P2 backlog） |
| 打卡统计 | 向用户展示连续打卡 | 不展示是既定原则（见 CONTEXT.md「连续打卡」）；若将来展示，改用「累计」这类只增不减的指标 |
| 付费墙 | 支付 / 订阅收费 | 产品价值验证 + 企业主体 + 小程序虚拟支付政策核实（Q14 / P1） |
| H5 / App | 跨端扩展 | 小程序验证跑通后再考虑 |
| 热门考点 / 高频考点列表 | 展示高频考点的 UI 入口 | 2026-08-06 定：不进 MVP，后期倾向不做；缺真实真题考频数据，有真实数据后再议 |

**备注（防误会）**:
- 连续打卡的**后台度量仍存在**——`/stats/summary` 返回 `streak_days`——只是刻意不向用户展示；"不做"的是"打卡展示功能"，不是"打卡数据"。
- 分享与基础埋点仍做（Q13 架构埋点），不做的是增长运营投入。

**Rationale**:
- 核心闭环（练习 → 错题 → 解析 → 强化）是留存引擎；每加一个非核心功能 = 从闭环抠时间。
- 竞品有 ≠ 我们该有：竞品拼功能广度，本项目 4 个月窗口只能拼深度（把题讲透）。
- 时间是这个项目最不可逆的资源，清单保护的是时间，不只是范围。

**代价**:
- 首版在"发现-获客"类功能上空白；接受不做增长投入（Q13 已定）。

**关键认知**:
- 非目标 ≠ 永不：每条都带重估条件，避免"当初说不做就永远不做"的路径依赖。
- 本清单是**范围护栏**：窗口期内被"竞品都有这个"诱惑时，先读这条再决定。

**仍待决（grilling 中，未列入本清单）**:
- **能力画像**（诊断/治疗/影像维度第三轴）——**不做**（2026-08-06 定）：记入待办，用户能力分析模块留待以后讨论；若将来做，从考点推导能力而非打标签。
- **备考视频**——外部文档新增功能，未在你的讨论记录中决策过。
