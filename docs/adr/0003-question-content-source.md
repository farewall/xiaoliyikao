# 题库内容来源：两类题（真题清洗变体 + AI 原创）+ AI 原创语料，真题原文不落库

医学考研 306 题库需要大量题目，而题目来源绕不开版权问题。教育部考试中心对考研真题**主张著作权**、设有授权机制（培训机构付费获得、限定课堂教学复制使用），并曾起诉盗版销售商维权（2006 深圳中法图案）；司法对"真题本身是否受著作权保护"存在争议（有观点认为客观题缺乏独创性、历年真题属公共资源），但**商业场景未获授权使用真题仍属有风险动作**。人卫版教材、贺银成等出版物作为正式教科书/解析书，**独创性无争议、明确受著作权保护**（已有"未经授权大量引用医考教材内容"被判侵权的判例）。

经 grill-with-docs 讨论（2026-08-04），内容策略从原"阶段一真题内测 → 阶段二清洗 → 阶段三语料原创"的渐进路线，改为**一步到位**：MVP 起即采用「两类题 + AI 原创语料」，真题原文、教材原文均不落库。

Status: accepted（2026-08-04 更新，取代原阶段一/二/三路线）

**决策核心**:
- **题库含两类题**:
  - **类1 · 真题清洗变体**：以真题为输入，**考点与考察点不变**，题干与选项的表述做合理变化（表层大改、"看起来不一样"但实质考察内容一致）。质量稳——核心（考点/干扰项逻辑/难度）是命题组验证过的。**优先级：类1先行**。
  - **类2 · AI 原创题**：按考点语料 AI 原创，需**重点人工审查**（凭空造题风险遍地：偏题/怪题/难度飘/医学事实错）。长期类2为主（源头干净）。
- **真题原文不落库**：只作类1清洗脚本的**一次性输入**（放产品库外参考目录），不进 `questions` 表；库从第一天只存终态形态（清洗后变体），迁移工作量为零。
- **语料 = AI 原创**：按大纲考点树组织，以人卫版教材章节为**参考**（不存原文），由 AI 用自己的语言重新表述、人工审校后入库。
- **解析 = AI 原创**，采用**考点中心写法**：讲考点与鉴别要点、正确项按内容点名、干扰项按内容说明，**不引用选项字母**——解析独立于题干措辞与选项排布，题目被清洗/改写后仍可复用、无需重写。
- **考点关联 = 主考点 + 附加考点**：一道题可关联多个考点。
  - `questions.knowledge_point_id` = **主考点**——驱动薄弱点统计与组卷归属（归因要单一干净，错题只记一个考点头上）；weakness.py / question_bank.py 零改动。
  - 新增关联表 `question_knowledge_points(question_id, knowledge_point_id)` = **附加考点**——只喂 RAG 检索广度（追问拉多个考点语料）；薄弱点、组卷不看它。
- **考点判断规则（出题/清洗/审校共用）**：
  - **主考点** = 正确选项直接指向的知识实体（诊断题=该疾病；机制题=该机制/概念）；题干是主考点的表现语境，不独立产生考点。
  - **附加考点** = 干扰项中「可鉴别」的实体（1~3 个）；纯凑数的干扰项不标。
  - **B 型题（配伍/共用选项）**：每个子题独立归因。主考点 = 正确选项指向的实体（同 A 型）；**附加考点 = 池内其余选项（全部，数量不受 1~3 上限约束）**——配伍池本质是鉴别集合，无凑数干扰项；若池子异构（跨主题），只标真实构成鉴别的。配伍主题（池子归属大类）对应语料的章节/父级考点，不进子题考点字段。
  - **否定式题**（选错误项）例外：主考点仍由题干主题框定，不由选项真假决定。严谨表述：主考点 = 题干主题 ∪ 正确选项，二者收敛于同一实体，有分歧时以正确选项为准。
  - 题干贡献的是**命题角度**，沉淀进语料的「鉴别要点/易错点」小节，不进考点字段。
- **题型 = 官方三型 `a/b/x`**（对齐 306 卷面，判分/组卷/模拟共用）：
  - `a` = A 型单选（含 A1 单句 / A2 病例 / **A3/A4 共享病例系列**——A3/A4 是 A 型的结构子形态，不独立成类型）。
  - `b` = B 型配伍（共用选项池，单选判分）。
  - `x` = X 型多选（正确项 ≥2，多选判分）。
  - **组题以「题组表」为单位（练习/模拟/记录回看全局统一）**：每题都归组（独立题 1:1，A3/A4 与 B 型 1:N）；共享内容只存题组一行——A3/A4 病例存 `question_groups.scenario`、B 型共用选项池存 `question_groups.options`；子题 `stem` 存纯问句、组内顺序用 `position` 显式保证。前端块状渲染：共享内容展示一次、子题按 position 连续排列；组卷按整块取题（抽到任一子题即拉整个题组）、按小题计数、**整块必进宁多勿拆**。反馈时机仍按模式（练习即时判、模拟考完判），属模式定义而非展示规则。（存储实现演进：最初拟 `series` 分组 + `scenario` 逐题重复的「存储冗余取舍」，后改为题组表集中共享内容——见 ADR 0004。）

**版权铁律**:
1. 解析必原创（考点中心，AI 自主重写，绝不抄出版物原文）。
2. 题干选项重新设计（类1换表述而非换考察点；类2全部原创）。
3. 参考思路不碰原文（角度可概括，原题不录入、不喂库）。
4. **语料必原创**（教材章节仅作参考，AI 用自己的话写，审校对照教材抽查近似原文段落）。

**考虑过的方案**:
- **真题原题直接入库（原阶段一）**：否决——库中持有未授权真题副本 + 公开前须批量清洗迁移。改为"清洗后变体入库"。
- **语料抄教材原文**：否决——教材独创性无争议，整章入库 = 复制受保护表达，源头污染（非"内测低风险"可洗）。
- **字面"变体"（真题原文长期喂系统）**：否决——改编权同为受保护权利，且持有/喂养真题原文与"不落库"目标冲突。

**关键认知**:
- 著作权侵权按被复制的部分**逐项判断**；"解析自己写"消除不了"题干是抄来的"。
- 客观题题干独创性低、版权状态**有争议**（部分判例认定不受保护）——类1清洗变体属**低维权风险灰色地带**（比照抄低，非法律豁免；老真题维权概率更低，但保护期 50 年、不存在"年头豁免"）。
- 教材（人卫）、解析书（贺银成）**独创性无争议**——只能参考思路，不能复制表达。

**连带结果 / 行动项**:
- 内容生产链（MVP 起即用）:
  ```
  大纲 → 考点树(knowledge_points 三级) → 教材章节(参考) → AI 原创语料 → 人工审校 → 入库
  真题原文(一次性输入) → AI 清洗 → 变体题(类1) → 人工审校 → 入库
  考点语料 → AI 原创出题(类2) → 人工审校 → 入库
  所有题 → AI 解析(考点中心) → 人工审校 → 入库
  ```
- 新增 `generate_questions.py`（两模式：--clean 清洗 / --original 原创；草稿 CSV → 审校 → 入库，复用 generate_explanations.py 模式）。
- 新增 `question_knowledge_points` 关联表（附加考点）；`rag.py` `_retrieve` 拉取主考点 + 全部附加考点语料；导入 CSV / 出题脚本输出「主考点 + 附加考点」。
- 改 `generate_explanations.py` prompt（考点中心、不引用选项字母）。
- 语料生产方式变更：大纲考点树导入 + AI 起草语料（教材电子版有则作起草输入，无则作审校对照）。
- 真题来源**缓办**（电子版或手工抄录；未找到前不阻塞——先跑考点树与语料）。
- 每道题过人工审校：考点对应、医学表述准确、选项无歧义。
