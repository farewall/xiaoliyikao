# 小鲤医考 — 医学考研刷题微信小程序

> 刷题 + AI 把题讲透。西医综合 306 考生备考助手。

## 产品定位

给冲刺阶段西医综合 306 考生用的「刷题 + AI 答疑」微信小程序。MVP 聚焦：

- 刷题（题库 + 答题 + 正确率）
- 真题解析 + 追问 AI 答疑（差异化核心）
- 章节薄弱点聚合
- 考点标签
- 免费层 AI 配额（每日限次，付费解锁后续接入）

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 原生微信小程序 |
| 后端 | Python + FastAPI |
| 数据库 | PostgreSQL + pgvector |
| AI | DeepSeek V4（RAG 答疑） |
