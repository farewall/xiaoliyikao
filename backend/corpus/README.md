# 考点语料库

RAG 答疑的知识语料源。**一个科目一个 Markdown 文件**（文件名即科目），人工编写/审校，导入脚本灌进数据库的 `knowledge_points.description`。

## 文件结构

```
corpus/
├── README.md        ← 本说明
├── import.py        ← 导入脚本
├── 生理学.md
├── 生物化学.md
├── 病理学.md
├── 内科学.md
└── 外科学.md
```

## Markdown 格式

```markdown
# 生理学                        ← 文件标题(忽略,科目取文件名)

## 章节: 呼吸系统                ← 章节

### 考点: 肺通气                ← 考点名(与 knowledge_points.name 对应)

**核心讲解**                    ← 小节标题(固定四个)
{200~500 字,定义/原理/机制/公式}

**鉴别要点**
{易混淆概念对比,每条一行}

**易错点**
{考试常挖的坑,每条一行}

**记忆口诀**
{可选}

**关联考点**
{可选。相关考点名,每行一个;导入时解析成考点↔考点边,驱动「相关考点」导航}
```

小节固定五个：**核心讲解 / 鉴别要点 / 易错点 / 记忆口诀 / 关联考点**（记忆口诀、关联考点可省略）。

## 导入

```bash
cd backend
.venv/Scripts/python.exe corpus/import.py
```

**幂等**：按 (科目, 章节, 考点名) 更新或插入，重复执行安全。同名考点会**更新 description**（已有的题目关联不受影响）；新考点会插入。

## ⚠️ 编写要求

- **医学准确性必须人工审校**——AI 起草的初稿核对后再入库，错的医考内容比没有危害大
- **不抄教材原文**（版权）——自主编写 / AI 起草后改写
- 内容深度 > 考点数量：先做**高频考点**，每科前 10 个做厚，再铺开
